# Скрипт для выбора группы из микрофона и наушников

Проблема: В системе больше одного устройства ввода и больше одного устройства вывода.
Нужна возможность создавать комбинации из нужного микрофона и наушников, через стандартный трей долго.

Решение: При запуске системы создается иконка в трее, которая позволяет одним нажатием выбрать нужную комбинацию из наушников и микрофона

Зависимости:
Qt
```bash
sudo apt install qt6-base-dev
```

Сборка:
```bash
g++ main.cpp -o audio-switch `pkg-config --cflags --libs Qt6Widgets`
```

Работоспособность гарантирована на Linux Mint 22.3
